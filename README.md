# GNYC Youth Store — Concept Mockups

Shareable, static concept mockups for the GNYC Youth Store redesign.

**Live preview:** https://gnyc-youth-department.github.io/youth-store-mockups/

| Page | File |
|------|------|

These are **static mockups** (no backend, no data) for sharing the concept. Product
images are GNYC's own; program tiles use the official Adventurer / Pathfinder / Master
Guide / AY Ministries / TLT logos. Prices and stock numbers are illustrative placeholders.

> Implementation docs, architecture, and decisions live in the private
> `GNYC-Youth-Department/website` repo.
