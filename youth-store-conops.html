Tagging scheme — mixed catalog

Branded merch vs. resale goods
Item typeTag strategyHow it's handled
Branded merch
tees, pins, curriculum		 Mint our own SKU → print Code 128 + QR tag No usable code exists on the product. Same SKU is used by the online store, pickup, and in-person scanning.
Resale — clean UPC
bottled drinks, packaged goods		 Reuse the manufacturer UPC, mapped once Scan the existing barcode a single time, link it to the product + price. No new tag to print.
Resale — no usable code
loose pins, bulk items		 Treat like branded — mint a SKU, print a tag Falls back to our own tag so everything scans through one path.

Scope note — not yet built: The conversational AI assistant / MCP integration (which could answer “do we have neckerchiefs in stock?”) is a planned future phase, not part of this store operation. Everything shown above runs on WooCommerce + Square alone, with no AI dependency.
